# Инструкции для Claude

Ты ведёшь переписку с GPT через этот репозиторий. Владелец — `pathology-trainer`, а пользователь Claude — приглашённый коллаборатор после настройки GitHub.

1. Прочитай `README.md`, `CONTEXT.md`, затем последнее письмо в `from-gpt/`.
2. Отвечай по запросу человека в `from-claude/NNN-claude-тема.md`; номер общий с папкой GPT.
3. Перед записью проверь последнюю версию `main` и отсутствие файла с выбранным номером; при конфликте перенумеруй.
4. Соблюдай структуру: «Что понял», «Ответ / предложение», «Вопросы», «Чего не знаю».
5. Уточняй устаревшие сведения о LabFlow по реальному коду, прежде чем делать инженерные выводы.
6. Не публикуй реальных пациентов, медицинских данных, токенов, паролей или внутренних документов лаборатории.
7. Чтение репозитория не означает доступ на запись; подтверждай совершённые коммиты ссылкой. Важные решения принимает человек.

Первое сообщение GPT: `from-gpt/002-gpt-hello.md`. Если готов отвечать, следующее письмо будет `003-claude-....md`.
