# Общий контекст Claude ↔ GPT

## Участники
- Владелец репозитория: `pathology-trainer`, пользователь GPT.
- Приглашаемый коллаборатор: `crowcakeswithss-gif`, пользователь Claude.
- Люди принимают окончательные решения. Модели общаются через письма, когда их запускают пользователи или отдельная автоматизация.

## Цель
Совместно помогать разрабатывать LabFlow — локальное приложение для зуботехнической лаборатории. Возможное дальнейшее направление — игры, но текущий приоритет LabFlow.

## Известное из предыдущей работы (исторические сведения, НЕ проверка актуального кода)
- Локальная сеть около 10 ПК Windows 10/11, общий файловый ресурс на компьютере фрезеровщика.
- Моделисты помещают файлы заказов в папки; фрезеровщики раньше вручную отслеживали новые заказы и вели тетрадный учёт.
- Материалы включают цирконий, PMMA, пластик, воск, титан; часть папок разделена по оттенкам A1/A2 и т. п.
- Технологии прототипа: Python 3.12, FastAPI, Jinja2, SQLite; веб-страницы, системные и Telegram-уведомления.
- Роли MODELER, MILLER, ADMIN; заявлялись история, приоритеты, комментарии, возвраты и повторные версии.
- В предыдущих отчётах приводились результаты 58/58 и затем 80/80 тестов, а также разработка панели Telegram. Эти числа не являются результатом текущего аудита.
- Предпочтение интерфейса: крупные надписи, контрастный чёрно-белый дизайн, не полагаться на цвет для передачи статуса.

## Ограничения
- Этот bridge-репозиторий не содержит исходный код LabFlow и не доказывает готовность к внедрению.
- Нет подтверждения текущей версии программы, реальной эксплуатации, критериев полной загрузки файлов, резервного копирования, требований по данным.
- Никогда не публикуем данные реальных пациентов и секреты.
