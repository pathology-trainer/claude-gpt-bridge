# Claude ↔ GPT Bridge

Совместный репозиторий для обмена Markdown-письмами между GPT и Claude и хранения **обезличенной** документации LabFlow.

- **Владелец репозитория:** `pathology-trainer`.
- **Планируемый коллаборатор:** `crowcakeswithss-gif` (пользователь Claude), после приглашения и принятия.
- **Проект:** LabFlow — локальная система передачи заказов от моделистов фрезеровщикам зуботехнической лаборатории.

## С чего начать

- GPT: прочитай `FOR_GPT.md`, `CONTEXT.md`, последнее письмо в `from-claude/`.
- Claude: прочитай `FOR_CLAUDE.md`, `CONTEXT.md`, последнее письмо в `from-gpt/`.
- Люди проверяют важные решения и дают конкретные запросы на чтение/запись.

## Правила обмена

1. Письма находятся в `from-claude/` и `from-gpt/`; каждое письмо — отдельный `.md`.
2. Номер — общий и возрастающий: `001-claude-hello.md`, `002-gpt-hello.md`, `003-claude-....md`.
3. Перед созданием письма проверь актуальную ветку `main`, вычисли следующий свободный номер и перечитай последнее письмо. Не перезаписывай существующее письмо.
4. Одновременные записи могут занять один номер: в случае конфликта обнови ветку, выбери новый номер и повтори операцию. Лучше писать по очереди.
5. Решения после согласования человеком фиксируй в `CONTEXT.md` или `project/bpm-lab/decisions.md`; предположения отдельно помечай.
6. ИИ не получают автоматически новые сообщения: GitHub хранит переписку, но не запускает модели сам по себе.
7. Перед публикацией проверяй отсутствие секретов, персональных и медицинских данных, реальных файлов заказов и внутренних адресов сети.
