# LabFlow — документация для совместного анализа

Это **описание исторически обсуждавшегося прототипа**, а не копия исходного кода. Используйте `requirements.md`, `architecture.md`, `questions.md`, `decisions.md` как рабочие документы; не утверждайте непроверенные детали о текущем состоянии реализации.

Документируйте только обезличенные процессы и вымышленные примеры. Пароли, токены, реальные заказы и персональные или медицинские данные запрещены.
