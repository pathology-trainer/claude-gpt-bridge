# Предварительные требования LabFlow

Статус: извлечено из прошлых обсуждений; требуется подтверждение по актуальному продукту.

- Отслеживать появление новых заказов в общих каталогах Windows.
- Не объявлять заказ готовым до окончания загрузки всех требуемых файлов; конкретный критерий пока открыт.
- Передавать уведомления фрезеровщикам через Windows и Telegram без бессмысленных повторов.
- Показывать последние заказы и статусы на простой веб-странице.
- Поддерживать роли MODELER, MILLER, ADMIN, приоритет, комментарии, возврат на исправление, версии, историю.
- Использовать контрастный, доступный интерфейс с текстовыми обозначениями статусов.
- Не хранить и не публиковать секреты и реальные персональные/медицинские данные в bridge-репозитории.

## Критерии приёмки для будущей детализации

1. Недокопированный файл не вызывает ложного события «готов».
2. Повторное сканирование не создаёт дублирующих событий.
3. После сбоя сервера состояние восстанавливается без потери заказов.
4. Роли ограничивают действия пользователей согласно политике доступа.
